Personal Finance Tracker

Project Type: AI-Assisted Web Development
Year: 2026
Status: Version 1.0 — Published

Project Overview

An interactive personal finance tracking website designed to help users record, organize, and understand their daily income and expenses through a clean and intuitive dashboard.

Key Features

	•	Record income and expenses with dates, categories, amounts, and optional notes.
	•	View monthly income, expenses, and net balance.
	•	Analyze spending by category.
	•	Explore daily expenses through an interactive calendar.
	•	Review and edit transaction histories.
	•	Store data locally in the user’s browser without requiring an account.
